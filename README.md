# 🚗 Tá na Garagem

**Marketplace automotivo para conectar compradores e vendedores de veículos em todo o Brasil.**

O Tá na Garagem é uma plataforma em desenvolvimento que busca simplificar a compra e venda de veículos, permitindo que particulares e lojas anunciem seus automóveis e alcancem novos compradores.
